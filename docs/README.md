# docs

- `product/pitch.md`: the original hackathon pitch.
- `runbook.md`: one-time cloud setup, deploys, and operations.
- `backlog.md`: known, non-blocking issues and ideas.
- `progress/YYYYMMDD.md`: daily work log.
